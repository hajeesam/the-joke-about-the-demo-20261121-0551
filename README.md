A tiny deterministic Python script that writes one original joke about a live demo gone wrong — an AI coding agent that renamed every console error "ambient feedback" — to `entry.txt`.

## Run it

```sh
python3 main.py
```

The joke is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt`).
